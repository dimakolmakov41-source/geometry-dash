# GEOMETRY DASH

Небольшая браузерная аркада-платформер в духе классического Geometry Dash. Проект сделан на HTML, CSS и JavaScript и подходит для публикации через GitHub Pages.

## Файлы
- `index.html` — структура игры.
- `style.css` — оформление и адаптация под телефон.
- `script.js` — игровой цикл, физика прыжка, препятствия, звук и сохранение рекорда.

## Как играть
- Нажимай на игровое поле или используй **Пробел**, **↑** или **W**, чтобы прыгать.
- Избегай шипов и блоков.
- Нажми **Ⅱ** или клавишу **P**, чтобы поставить игру на паузу.
- После столкновения нажми «Повторить».
- Клавиша **Esc** также управляет паузой.

## Запуск
Открой `index.html` в браузере или включи GitHub Pages в настройках репозитория:
**Settings → Pages → Deploy from a branch → main → /(root)**.

После публикации сайт будет доступен по адресу:
https://dimakolmakov41-source.github.io/geometry-dash/

## Особенности
- Управление касанием для мобильных устройств.
- Автоматическое движение уровня и прыжки с физикой.
- Прогресс прохождения и локальный рекорд.
- Пауза, перезапуск и звуковые эффекты.
- Геометрическая разноцветная графика без неонового оформления.
